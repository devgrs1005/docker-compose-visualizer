# Docker Compose Visualizer

## Privacy Policy

Last updated: 2026-09-11

Docker Compose Visualizer ("the Plugin") does not collect, store, or transmit any personal data, telemetry, or usage analytics.

### What the Plugin does with your data

The Plugin reads and writes only the `docker-compose.yml` file(s) you open in your IDE, entirely on your local machine. No file contents, file paths, or project information are ever sent anywhere.

### Licensing

License status for the paid features is checked locally via the IDE's built-in `LicensingFacade` API. The Plugin itself makes no network requests to verify or report license status.

If You purchase a license, that transaction is handled entirely by JetBrains Marketplace, which acts as merchant of record and processes any personal data (e.g., payment and account details) under its own privacy policy: https://www.jetbrains.com/legal/docs/privacy/privacy/
